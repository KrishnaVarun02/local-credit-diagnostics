# Related work and source verification

Primary publication records and the closest PDFs were checked on **2026-10-01**. This is a focused review; it does not establish novelty or exhaust research through this date. No third-party algorithm was executed or copied.

| Primary source | What is already established | Difference and limitation of this package |
|---|---|---|
| [VDN, AAMAS 2018](https://www.ifaamas.org/Proceedings/aamas2018/pdfs/p2085.pdf) | Learning additive team-value decompositions. | Our function class is additive, but the estimator is one-shot least squares, not recurrent VDN training. |
| [QMIX, ICML 2018](https://proceedings.mlr.press/v80/rashid18a.html) | Monotonic mixing with consistent utility-wise maximization. | We do not implement the mixing network, learning, or benchmark evaluation. |
| [QTRAN, ICML 2019](https://proceedings.mlr.press/v97/son19a.html) | Transformation-based factorization beyond additive/monotonic representations. | Its established 3×3 matrix appears only as an additive-fit sanity check; not an algorithm reproduction. |
| [Weighted QMIX, NeurIPS 2020](https://papers.nips.cc/paper_files/paper/2020/hash/73a427badebe0e32caa2e1fc7530b7f3-Abstract.html) | Unweighted projection can choose the wrong action; suitable weighting can preserve valuable actions. | Closest conceptual prior art. We quantify an elementary sparse-synergy family and release reproducible diagnostics. No first-discovery claim. |
| [Deep Coordination Graphs, ICML 2020](https://proceedings.mlr.press/v119/boehmer20a.html) | Pairwise value factors and message passing for action selection. | Pairwise basis ablation only; central exact enumeration intentionally removes inference error. |
| [LOMAQ, AAAI 2022](https://ojs.aaai.org/index.php/AAAI/article/view/20915) | Local rewards with cooperative structural conditions; Section 4.2 discusses reward decomposition and Figure 6 illustrates locality misspecification. | We deliberately violate limited-order reward structure. This does not refute LOMAQ's conditional guarantees. Correct publication year is 2022. |
| [Le and Ta, arXiv:2601.21523v2, 2026](https://arxiv.org/abs/2601.21523v2) | Recent dependence-graph approach combining local reward information with cooperation. | Context only; record identifies a preprint, not a verified venue publication or baseline evaluated here. |

The [official Weighted QMIX repository](https://github.com/oxwhirl/wqmix) was inspected at the README level. It documents separate CW/OW implementations, version-specific StarCraft requirements, and experiment-dependent hyperparameters. Those components are absent here, so a comparison labeled “WQMIX reproduction” would be inaccurate.

## Evidence supporting or contradicting the scoped claim

The exact theorem and exhaustive numerical agreement support the specific absolute-MSE/decision mismatch. Strong normalized accuracy is **not** supported: normalized MSE approaches one. If the complete-design least-squares optimum or maximizing actions had disagreed with the proof, the claim would fail and the implementation/proof would need correction. The supplied tests compare independent solve routes and known representable controls.

The practical question of whether these diagnostics predict failures in trained sequential systems remains unresolved **by this package**, not necessarily unresolved in the literature. A publication novelty assessment needs broader and deeper review before academic submission.
